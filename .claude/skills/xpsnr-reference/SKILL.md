# XPSNR reference scores

The cases live in `CASES` in `crates/rusplay-core/src/quality/reference_tests.rs`. Each is a
deterministic three-frame sequence generated by the test itself; the expected Y, U and V scores
are what FFmpeg's `xpsnr` filter reports for the third frame.

1. Add or change the case in `CASES` (name, size, chroma, depth, frame rate) with any expected
   values, for example `[0.0, 0.0, 0.0]`.
2. Run `scripts/xpsnr-reference.sh <scratch directory>`. It runs the ignored
   `write_xpsnr_fixtures` test with `RUSPLAY_XPSNR_FIXTURE_DIR` set, which writes
   `<case>.src.yuv`, `<case>.rec.yuv` and `cases.txt`, then runs
   `ffmpeg -lavfi "[0:v][1:v]xpsnr,metadata=print:file=-"` on each pair and prints
   `<case> <y> <u> <v>` for frame 2.
3. Copy the printed scores into the case's `expected`, grouping the six decimals as
   `34.303_249` for clippy's `unreadable_literal`, and run
   `cargo test -p rusplay-core xpsnr_matches_ffmpeg_on_the_reference_sequences`. The tolerance is
   0.001 dB.
4. A sequence in the downsampled path (more than 2048x1152 luma samples) must have an even width
   and height: FFmpeg reads one sample past an odd block there, from row padding whose contents
   depend on the bit depth, so it is no reference.
